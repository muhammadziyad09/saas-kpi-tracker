# SaaS KPI Tracker

> **SAMPLE DATA / PORTFOLIO DEMONSTRATION ONLY**
>
> This project is built on sample data to demonstrate the service. It is not client work, and no client data is included or reused.

## Scope

- Sample global SaaS subscription KPI data covering July 2024–June 2026
- KPIs tracked in the source sample: monthly recurring revenue (MRR), annual run rate, customers, churn, and LTV:CAC
- Workbook structure in the source sample: Dashboard, Data, and Insights sheets

## What was done

- Data cleaned and checked with Python (pandas)
- Modelled in Excel with live-formula KPI dashboards
- Pivot analysis and native Excel charts
- A written Insights sheet accompanying the dashboard

## Tools

Excel, Python (pandas), pivot tables, native charts.
